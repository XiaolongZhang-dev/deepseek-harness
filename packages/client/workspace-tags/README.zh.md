# @deepseek-ai/dsh-client-workspace-tags

[English](README.md) | 中文

## 概述

在浏览器侧给工作区打标签，并按标签收窄工作区列表。工作区右键菜单打开标签编辑弹窗，工作区行展示标签，工作区浏览器的「视图选项」新增「按标签筛选」分组；该分组里的「管理标签…」可跨所有工作区重命名或删除一个标签。

标签词表是全局的：由各工作区的引用并集得出，没有引用的标签自动消失。

## 使用方式

把插件组合进 Web profile：

```yaml
- id: workspace-tags
  name: '@deepseek-ai/dsh-client-workspace-tags'
```

浏览器半注册到 ui-workspace 的两处通用扩展点（`workspaceViewFilters` 与 `sidebar.workspaces.workspace.row.trailing`），因此插件本身不修改工作区浏览器。

Host 半声明 `assignments` 配置字段：持久化的「工作区 id → 标签列表」映射，通过通用设置 Remote 读写。命名空间就是 profile 行 id（`workspace-tags`）。

### 限制

| 规则 | 取值 |
|---|---|
| 标签名 | 去首尾空白后 1–24 个字符，禁止控制字符 |
| 单工作区标签数 | 10 |
| 全局标签数 | 50 |
| 去重 | 大小写不敏感，保留首次写法 |

工作区行最多展示 2 个标签加 `+N` 余量；悬停胶囊会列出全部标签。工作区注册表已不再包含的条目会在下一次读取时被清理。

## 模型体验

本包不新增工具、提示词、请求上下文或会话事件，对模型不可见。Token、成本与 KV-cache 影响：无。

## 已知限制与后续工作

- 其他窗口的修改要等本窗口下一次读取（插件加载或本地保存）才同步；这里没有订阅设置变更事件。
- 行内胶囊与两个弹窗尚无组件级测试；插件体、扩展点与标签规则已有覆盖。
- 扩展点会缓存筛选器的菜单项与谓词，直到筛选器重新注册；本插件在每次状态变化时重新注册，未来的筛选器也必须遵守同一约定。
